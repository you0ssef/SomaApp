## ✨ المميزات

* تصفح واستكشف مقالات ويكيبيديا بأسلوب الـ Reels (تمرير عمودي).
* حدد اهتماماتك لجلب مقالات مخصصة لتفضيلاتك.
* حفظ المقالات محلياً للقراءة في أي وقت بدون اتصال بالإنترنت.
* واجهة قراءة نظيفة ومنظمة لتركيز أفضل.
* تخصيص تجربة القراءة عبر تغيير حجم الخط والتبديل بين الوضع الفاتح والداكن.
* نسخ رابط المقال أو فتحها في متصفح خارجي.
* التطبيق متوفر بعدة لغات، مع إضافة المزيد في التحديثات القادمة.
