## ✨ Features

* Browse and discover Wikipedia articles in a modern, vertical scroll (Reels) format
* Set your interests to get articles tailored to your preferences
* Save articles locally to read them anytime without an internet connection
* A clean and organized reading interface for better focus
* Customize your experience by adjusting font size and switching between light/dark themes
* Easily copy article links or open them in an external browser
* Available in multiple languages, with more being added
